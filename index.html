02 // 範式演進對比 實證：單純 LLM 真實任務成功率僅 12%–14%

從被動文本生成器到自主 AI Agent：為何需要新範式？

傳統思維鏈（CoT）屬於靜態黑箱推理，缺乏外部環境接地（Grounding），容易發生事實幻覺與錯誤累積

A. Standard 標準提示
單次輸入 → 直接輸出
Input: 問題
↓ 無中間推理
Output: 直接給答案

無法拆解多步驟問題，遇到需要外部檢索或計算的任務即失效。

B. CoT 僅推理
靜態內部思維鏈
Thought 1 → Thought 2
↓ 依賴參數內記憶
易產生「事實幻覺」

雖能規劃推理結構，但無法查證外部世界，一旦某步出錯就會產生錯誤傳播。

C. Act-only 僅行動
無思考直接觸發工具
Action → Observation
↓ 缺乏目標追蹤
陷入重複無效動作

缺乏語言工作記憶（Working Memory），難以在長程互動任務中整合線索與調整目標。

D. AI Agent 自主閉環
感知 × 思考 × 行動 × 記憶
Thought（推理規劃）
⇄ Action（環境工具）
⇄ Observation（更新記憶）

將語言推理與外部環境執行緊密結合，透過記憶累積與回饋修正實現長期一致性。

關鍵演進公式：LLM Agent = LLM 核心引擎 + 角色指令（Instruction）+ 記憶模組 + 規劃與行動介面（Interface）
AgentBench：單純 LLM 成功率僅 12%–14%

04 // 行動空間擴展 NeurIPS 2023 · 自監督工具學習

突破模型參數邊界：Toolformer 如何自學調用外部 API？

透過「位置採樣 → API 執行 → 損失函數過濾」的閉環訓練，讓語言模型自主決定何時與如何呼叫工具

實戰預測範例（Toolformer 論文 Figure 1） 自主插入 API 標記
機器翻譯：The name derives from "la tortuga", the Spanish word for [MT("tortuga") → turtle] turtle.
維基檢索：The Brown Act is California's law [WikiSearch("Brown Act") → The Ralph M. Brown Act is an act of the California State Legislature…] that requires legislative bodies…
為何需要自監督工具過濾？ Action Space 核心機制
1. 不依賴大量人工標註：僅需少數 Few-shot 提示即可從未標註語料庫自動生成數千筆有效工具呼叫資料。
2. 保留原生語言能力：僅在 API 回傳確實能幫助預測後續 Token 時才納入訓練，避免無意義濫用工具。
3. 跨基準表現飛躍：GPT-J 基礎模型在 LAMA 問答與數學計算基準中，藉助 QA 與 Calculator 工具超越體積更大的 GPT-3。
引用出處：Schick et al. (2023) "Toolformer: Language Models Can Teach Themselves to Use Tools" (NeurIPS 2023, Fig. 1, Sec. 2 & Table 3) SLIDE 04

06 // 三維記憶檢索機制 Generative Agents · 記憶流架構

長期記憶如何精準提取？三維記憶檢索（Recency · Importance · Relevance）

借鏡人類認知記憶（短期 Context Window + 長期外部記憶流），以三大維度動態評分並提取最相關經驗

檢索失誤提醒：若三維檢索未能抓回正確片段（如 Rajiv Patel 雖聽聞 Sam 參選卻回答「未密切關注選舉」），會導致角色行為一致性下降。
三維檢索權重模擬器（情境：Maria 思考傍晚行程）

07 // 高階認知與湧現 Smallville 虛擬小鎮實證

從記憶到抽象洞見：Reflection 反思、Planning 規劃與湧現社交行為

低階記憶流透過「階層式反思」濃縮為高階自我認知，再搭配由上而下的遞迴規劃，湧現出未經寫死的社交協調

階層式反思（Memory Reflection） Klaus Mueller 案例
由上而下遞迴規劃：先草擬整日粗略行程，再細化為具體時間、地點與動作（如「2/12 9:00 起在宿舍書桌閱讀與筆記 180 分鐘」），並能依突發事件動態改寫。
Smallville 湧現社交行為實錄（無人工腳本） 3 大湧現現象
1. 資訊擴散（Information Diffusion）
Sam 在雜貨店告訴 Tom 自己要參選鎮長後，選舉消息透過代理間日常對話自然傳遍小鎮。
2. 關係記憶（Relationship Memory）
Sam 偶遇 Latoya 得知她在進行攝影計畫；日後再遇時主動關心：「Hi, Latoya. 你的攝影計畫進展如何？」
3. 自主活動協調（Valentine's Day Party）
使用者僅設定初始種子：Isabella 想在 2/14 17:00–19:00 於 Hobbs Cafe 舉辦派對、Maria 暗戀 Klaus。
結果：Isabella 主動發送邀請並於 2/13 佈置咖啡廳、邀 Maria 幫忙；Maria 鼓起勇氣邀請 Klaus；最終 5 位代理準時現身共度派對！
引用出處：Park et al. (2023) "Generative Agents" (Sec. 3.4 & Sec. 4); Wang et al. (2024) Memory Reflection (Sec. 2.1.2) SLIDE 07
08 // 多代理協作系統（MAS） 點選切換 3 種業界主流多代理拓撲

從單兵作戰到團隊協作：Multi-Agent Systems 與 AutoGen 範式

代理形式化為 a = {m, o, e, x, y}，透過可對話代理與對話程式設計完成跨專業分工與除錯

多代理協作核心優勢與應用矩陣

AutoGen 對話程式設計：將應用統一為多代理對話，融合自然語言控制與 Python 終止條件；在供應鏈 OptiGuide 系統中將核心程式碼從 430+ 行縮減至 100 行。
專業分工實踐：MetaGPT / ChatDev（產品經理、設計與程式員）、MedAgent（多專科醫師會診）、MARG（論文同儕審查）、AgentCF（用戶與物品雙代理推薦）。
IBM Bee 框架亮點：支援代理狀態「序列化（Serialization）」，可在複雜長程工作流中安全暫停並無損恢復執行。
公式：y = m(o, e, x)，其中 m = {arch, mem, adp} 支援 Human-in-the-loop

實證分析：為何多輪任務常失敗？
主因一：TLE（超過任務輪數上限） 高重複率陷阱

研究以 ROUGE-L 指標偵測發現：大量任務失敗源自模型在最後幾輪反覆輸出幾乎相同的內容，陷入死胡同而耗盡輪數上限。

主因二：商業 API vs 開源模型鴻溝 指令遵循落差

評測 29 款模型顯示，頂尖商業 API 模型遠超參數規模 ≤70B 的開源模型；開源模型常因格式錯誤、長期推理與指令遵循能力不足而提前中斷。

發現三：程式碼訓練的雙面刃效應 權衡取捨

強化程式碼訓練雖有助於 OS / DB 等結構化任務，卻可能在其他需要常識或開放式互動的代理任務上造成表現下滑。

架構貢獻：採用 HTTP Server–Client 模組化設計，可標準化評估任意 LLM。
引用出處：Liu et al. (2024) "AgentBench: Evaluating LLMs as Agents" (ICLR 2024, Sec. 3, Table 2 & Appendix J.2.4) SLIDE 09
10 // 安全與隱私治理 虛擬小鎮評測：僅 38.5% 兼顧隱私與權限安全

當代理能操作真實工具：安全威脅分類與縱深防禦架構

除繼承自底層 LLM 的脆弱性外，Agent 專屬的工具權限與多代理通訊更帶來知識投毒與連鎖誤導風險

兩大威脅來源分類 風險面放大
1. 繼承自 LLM 的威脅（Inherited Threats）
技術脆弱性：幻覺（Hallucination）、災難性遺忘、複雜推理誤解。
惡意攻擊：越獄（Jailbreaking）套取商業機密、提示詞注入（Prompt Injection）、訓練資料萃取與成員推論攻擊。
2. 代理專屬威脅（Agent-Specific Threats）
知識投毒：污染外部知識庫或記憶流，誘發錯誤決策。
輸出與功能操縱：欺騙人類或誤導下游工具執行高風險操作。
多代理連鎖效應：單一節點產生幻覺或被動竊聽 / 主動散播釣魚與惡意檔案，會沿通訊拓撲擴散至整個系統。
核心防禦機制與實證成效（Table 3） 縱深防禦
AirGapAgent（隱私與輸出防禦） 97% 隱私保護
實施資料最小化、上下文隔離（Context Isolation）與請求升級審核，在 97% 隱私防護下仍維持 88%–90% 任務效用。
ToolEmu（功能操縱動態沙盒） 減少 96.9% 建置時間
以語言模型模擬高風險工具執行並搭配自動安全評估器，在標準與對抗測試中分別達成 72.5% 與 68.8% 風險辨識精確率。
ParaFuzz & SAUP & ReCon 投毒與不確定性治理
ParaFuzz 以模型可解釋性偵測投毒；SAUP 跨推理步驟傳播不確定性（AUROC 提升達 20%）；ReCon 結合觀點轉換強化反欺騙能力。
